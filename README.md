A nerdy exploration into IFC, MVDs and model validation.

Originally started from the question: 
"Is IFC really the limitation, or are today's tools and processes the actual bottleneck?"

This project investigates model views, validation rules, geometry representations and 
use-case specific data exchange. The long-term goal is to better understand how IFC data 
can be structured, filtered and validated in a way that reduces information overload 
and improves interoperability.
