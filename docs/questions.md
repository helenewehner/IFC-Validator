Für das "Forschungsprojekt IFC-Validator" sollen folgende Fragen beantwortet werden:
- Können Bauteile in IFC parametrisch beschrieben werden?
- Kann die Ersteller-Historie für die Geometrie in IFC abgebildet werden?
- Welche Bereiche werden für MVDs tatsächlich verwendet?
- Welche Bereiche wären für einen AWF-spezifischen IFC Export für ein MVD relevant?
- Welche Bereiche wären für eine umfangreiche regelmasierte Verifizierung und Validierung einer IFC-Datei für ein MVD relevant?
- Wie können Regelsätze für die Erstellung und Prüfung von IFC-Dateien Anwenderfreundlich und -verständlich abgebildet werden?
- Wo stößt IDS an seine Grenzen?
- Welche Einschränkung bei der Definition von Regelsätzen gibt es mit MVD?
